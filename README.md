# Hero House Books (test site)

A sandbox for trying gift-book ideas. Every person, quote and drawing on it is made up. It takes no orders, stores no uploads and asks search engines not to index it.

- `index.html`: home page and gift finder
- `gifts/`: one page per gift idea, each with a sample book you can page through
- `gallery/maya.html`: a sample kids' art gallery
- `assets/`: styles, sample drawings (`art.js`), gift texts (`gifts.js`) and page rendering (`site.js`)
